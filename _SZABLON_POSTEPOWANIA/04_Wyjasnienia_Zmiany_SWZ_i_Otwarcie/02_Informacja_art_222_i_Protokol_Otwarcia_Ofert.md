# Protokół otwarcia ofert i Informacja z art. 222 ust. 4–5 Pzp

**Znak sprawy:** `[Uzupełnić]`

## CZĘŚĆ I: Informacja o kwocie przeznaczonej na sfinansowanie zamówienia (art. 222 ust. 4 Pzp)

> **Wymóg:** Zamawiający, **bezpośrednio przed otwarciem ofert**, podaje do wiadomości (na stronie prowadzonego postępowania) kwotę, jaką zamierza przeznaczyć na sfinansowanie zamówienia.

Zamawiający — Gmina `[Nazwa]` — informuje, że na sfinansowanie zamówienia pn. **`[Nazwa zamówienia]`**, znak sprawy **`[Znak sprawy]`**, przeznacza kwotę:

**`[0,00]` PLN brutto** (słownie: `[...]`)

*(Kwota ta jest kwotą brutto, zabezpieczoną w budżecie Gminy na rok `[...]`, Dział `[...]`, Rozdział `[...]`, Paragraf `[...]`).*

Opublikowano na stronie prowadzonego postępowania dnia `[RRRR-MM-DD]` o godz. `[GG:MM]`, przed otwarciem ofert o godz. `[GG:MM]`.

---

## CZĘŚĆ II: Informacja z otwarcia ofert (art. 222 ust. 5 Pzp)

> **Wymóg:** Niezwłocznie po otwarciu ofert Zamawiający udostępnia na stronie prowadzonego postępowania informacje o złożonych ofertach.

Zamawiający — Gmina `[Nazwa]` — informuje, że w dniu `[RRRR-MM-DD]` o godz. `[GG:MM]` nastąpiło otwarcie ofert złożonych w postępowaniu pn. **`[Nazwa zamówienia]`**, znak sprawy **`[Znak sprawy]`**.

W terminie składania ofert (do dnia `[RRRR-MM-DD]` godz. `[GG:MM]`) złożono następujące oferty:

| L.p. | Nazwa i adres Wykonawcy | Cena brutto (PLN) | Okres gwarancji (mies.) | Termin realizacji | Inne kryterium |
| :-- | :-- | ---: | :--: | :-- | :-- |
| 1 | | | | | |
| 2 | | | | | |
| 3 | | | | | |

Ofert złożonych po terminie / wycofanych: `[brak / liczba i opis]`

Opublikowano niezwłocznie po otwarciu ofert, dnia `[RRRR-MM-DD]` o godz. `[GG:MM]`.

## CZĘŚĆ III: Informacja do Prezesa UZP — art. 81 ust. 1 Pzp

> **Wymóg:** Zamawiający przekazuje Prezesowi UZP informację o złożonych wnioskach o dopuszczenie do udziału lub ofertach — **nie później niż w terminie 7 dni od dnia otwarcia ofert / unieważnienia postępowania** — przez platformę e-Zamówienia.

- Data otwarcia ofert / unieważnienia: `[RRRR-MM-DD]`
- **Nieprzekraczalny termin przekazania informacji:** `[RRRR-MM-DD]` *(data otwarcia + 7 dni)*
- Data faktycznego przekazania: `[RRRR-MM-DD]`
- Potwierdzenie przekazania (numer referencyjny na e-Zamówieniach): `[...]`
